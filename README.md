# Cine Verse

## Sobre o Projeto

[Cine Verse](https://cine-verse-dun.vercel.app/) é um projeto desenvolvido utilizando **React**, com o objetivo de listar e exibir informações sobre filmes de forma dinâmica. O projeto foi criado para uma competição amistosa entre alunos.

## Tecnologias Utilizadas

- **React.js**
- **JavaScript (ES6+)**
- **HTML5**
- **CSS3**
- **React Hooks** (useState, useEffect)
- **React Router DOM**
- **Consumo de API** (para busca de filmes)

## Funcionalidades Implementadas

- Listagem de filmes consumindo uma API
- Pesquisa dinâmica com **onChange**, onde a lista de filmes é atualizada em tempo real conforme o usuário digita
- Exibição de detalhes do filme
- Interface estilizada de forma personalizada

## Como Executar o Projeto

1. Clone o repositório:
   ```bash
   git clone https://github.com/MattMori/MovieList.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd MovieList
   ```
3. Instale as dependências:
   ```bash
   npm install
   ```
4. Execute o projeto:
   ```bash
   npm run dev
   ```
5. O projeto estará disponível em **http://localhost:3000**
